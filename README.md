# Pantry Telegram Bot

Telegram-бот для домашнего учёта продуктов. Пользователь добавляет продукты текстом
или отправляет фотографию чека/продуктов, проверяет распознанный список, а затем
получает идеи блюд из текущих запасов.

## Решаемая проблема

Люди забывают, что уже находится дома, повторно покупают продукты и не успевают
использовать их. Бот переносит учёт в привычный интерфейс Telegram и сокращает
ручной ввод с помощью распознавания изображений.

## Возможности MVP

- ручное добавление нескольких продуктов одной командой;
- объединение одинаковых позиций;
- просмотр и списание запасов;
- распознавание чека или фотографии продуктов;
- обязательное подтверждение AI-результата перед записью;
- три предложения блюд из текущих запасов;
- SQLite для локальной разработки и PostgreSQL в Docker.

## Быстрый запуск

Нужны Python 3.11+, токен Telegram-бота от `@BotFather` и API-ключ OpenAI.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
Copy-Item .env.example .env
```

Заполните `.env`, затем запустите:

```powershell
pantry-bot
```

Или через Docker:

```powershell
docker compose up --build
```

## Команды

```text
/add молоко 2 л; яйца 10 шт
/inventory
/consume яйца 2
/recipes
```

Фотографию можно отправить обычным сообщением. Бот создаёт временный черновик и
показывает кнопки «Добавить» и «Отменить». Без подтверждения база не изменяется.

## Поток обработки фотографии

```text
Telegram photo
      ↓
download to memory
      ↓
multimodal model → validated JSON
      ↓
pending_imports
      ↓
user confirmation
      ↓
pantry_items
```

Изображение не сохраняется на диск. В базе остаются только подтверждённые позиции и
временный JSON распознавания.
